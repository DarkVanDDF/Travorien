# `.agflow/` control plane

Business-neutral workflow metadata adapted from the validated Mendes Harness.

- `gate_profiles.yaml`: deterministic quality gates.
- `role_policies.yaml`: ownership and review routing.
- `templates/`: task, work-result, and review contracts.
- `tasks/`: local auditable task artifacts.
- `lessons/`: reusable process learnings; product decisions stay in `docs/`.

Lifecycle: `drafted → planned → implementing → reviewing → validating → handoff`.
